<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Configure Google OAuth and Supabase email template</name>
  <files>none (external dashboard configuration)</files>
  <action>
    Complete these 4 configuration steps in external dashboards.

    **Step 1: Google Cloud Console -- Create OAuth Credentials**

    1. Go to https://console.cloud.google.com/
    2. Select or create a project for KBPipe
    3. Go to "APIs and Services" -> "OAuth consent screen"
       - User Type: External
       - App name: KBPipe
       - User support email: your email
       - Authorized domains: add your production domain (e.g., kbpipe.com) and supabase.co
       - Developer contact: your email
       - Save and continue through Scopes (no extra scopes needed) and Test Users
    4. Go to "APIs and Services" -> "Credentials"
       - Click "Create Credentials" -> "OAuth client ID"
       - Application type: Web application
       - Name: KBPipe
       - Authorized redirect URIs: add `https://YOUR-PROJECT-REF.supabase.co/auth/v1/callback`
         (Find your project ref in Supabase Dashboard -> Project Settings -> General)
       - For local dev, also add: `http://127.0.0.1:54321/auth/v1/callback`
       - Click Create
       - Copy the **Client ID** and **Client Secret**

    **Step 2: Supabase Dashboard -- Enable Google Provider**

    1. Go to Supabase Dashboard -> Authentication -> Providers
    2. Find "Google" and toggle it ON
    3. Paste the Client ID and Client Secret from Step 1
    4. Save

    **Step 3: Supabase Dashboard -- Update Password Reset Email Template**

    1. Go to Supabase Dashboard -> Authentication -> Email Templates
    2. Select "Reset Password" template
    3. Replace the reset link in the template with:
       `<a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=recovery">Reset Password</a>`
       (Replace the default `{{ .ConfirmationURL }}` with the above)
    4. Save

    **Step 4: Supabase Dashboard -- Add Redirect URLs**

    1. Go to Supabase Dashboard -> Authentication -> URL Configuration
    2. Add to "Redirect URLs":
       - `https://your-production-domain.com/auth/callback`
       - `https://your-production-domain.com/auth/confirm`
       - `http://localhost:3000/auth/callback` (for local dev)
       - `http://localhost:3000/auth/confirm` (for local dev)
    3. Save
  </action>
  <verify>User confirms all 4 steps are complete by typing "configured"</verify>
  <done>Google OAuth credentials created and added to Supabase. Password reset email template updated with /auth/confirm URL. Redirect URLs allowlisted.</done>
</task>
