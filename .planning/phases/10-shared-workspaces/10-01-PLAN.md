Create `supabase/team-migration.sql` as a single BEGIN/COMMIT transaction with the following sections in order:

**1. Create enums:**
- `workspace_role` AS ENUM ('owner', 'admin', 'member') -- ordering matters: owner < admin < member for <= comparisons
- `invite_status` AS ENUM ('pending', 'accepted', 'expired')

**2. Create workspace_members table:**
```sql
CREATE TABLE workspace_members (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id uuid NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  role workspace_role NOT NULL DEFAULT 'member',
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE(workspace_id, user_id)
);
```
- Add indexes: `idx_wm_user(user_id)`, `idx_wm_workspace(workspace_id)`
- Add `update_updated_at` trigger
- Enable RLS

**3. Create workspace_invites table:**
```sql
CREATE TABLE workspace_invites (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id uuid NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
  email text NOT NULL,
  role workspace_role NOT NULL DEFAULT 'member',
  invited_by uuid NOT NULL REFERENCES auth.users(id),
  token uuid NOT NULL DEFAULT gen_random_uuid(),
  status invite_status NOT NULL DEFAULT 'pending',
  expires_at timestamptz NOT NULL DEFAULT (now() + interval '7 days'),
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE(workspace_id, email)
);
```
- Add indexes: `idx_invites_token(token)`, `idx_invites_email(email)`
- Enable RLS

**4. Create helper functions (SECURITY DEFINER):**

`is_workspace_member(ws_id uuid)` -- returns boolean, checks workspace_members for auth.uid()
`has_workspace_role(ws_id uuid, required_role workspace_role)` -- returns boolean, checks role <= required_role (uses enum ordering)

Both must be `LANGUAGE sql SECURITY DEFINER STABLE`.

**5. Create accept_workspace_invite(p_token uuid) function:**
- SECURITY DEFINER, LANGUAGE plpgsql
- Find invite by token where status='pending' AND expires_at > now()
- Verify auth user's email matches invite email (SELECT email FROM auth.users WHERE id = auth.uid())
- INSERT INTO workspace_members ON CONFLICT DO NOTHING
- UPDATE invite status to 'accepted'
- Return jsonb with success/workspace_id or error message

**6. CRITICAL: Backfill existing owners:**
```sql
INSERT INTO workspace_members (workspace_id, user_id, role)
SELECT id, user_id, 'owner'::workspace_role
FROM workspaces
ON CONFLICT (workspace_id, user_id) DO NOTHING;
```
This MUST happen BEFORE dropping old RLS policies.

**7. Drop old RLS policies and create new ones:**

On `workspaces`:
- Drop `ws_all`
- `ws_select`: FOR SELECT USING (is_workspace_member(id))
- `ws_insert`: FOR INSERT WITH CHECK (auth.uid() = user_id) -- creator is always owner
- `ws_update`: FOR UPDATE USING/WITH CHECK (has_workspace_role(id, 'admin'))
- `ws_delete`: FOR DELETE USING (has_workspace_role(id, 'owner'))

On `articles`:
- Drop `articles_select`, `articles_insert`, `articles_update`, `articles_delete`
- `articles_select`: FOR SELECT USING (is_workspace_member(workspace_id))
- `articles_insert`: FOR INSERT WITH CHECK (is_workspace_member(workspace_id))
- `articles_update`: FOR UPDATE USING (is_workspace_member(workspace_id))
- `articles_delete`: FOR DELETE USING (auth.uid() = user_id OR has_workspace_role(workspace_id, 'admin'))

On `workspace_preferences`:
- Drop `wp_all`
- `wp_select`: FOR SELECT USING (is_workspace_member(workspace_id))
- `wp_upsert`: FOR INSERT WITH CHECK (has_workspace_role(workspace_id, 'admin'))
- `wp_update`: FOR UPDATE USING (has_workspace_role(workspace_id, 'admin'))

**8. RLS on new tables:**

On `workspace_members`:
- SELECT: is_workspace_member(workspace_id) -- members can see other members
- INSERT: has_workspace_role(workspace_id, 'admin') -- admin+ can add members
- DELETE: has_workspace_role(workspace_id, 'admin') AND user_id != (SELECT wm.user_id FROM workspace_members wm WHERE wm.workspace_id = workspace_members.workspace_id AND wm.role = 'owner') -- can't remove owner
- UPDATE: has_workspace_role(workspace_id, 'owner') -- only owner changes roles

On `workspace_invites`:
- SELECT: is_workspace_member(workspace_id) -- members can see invites
- INSERT: has_workspace_role(workspace_id, 'admin') -- admin+ can invite
- DELETE: has_workspace_role(workspace_id, 'admin') -- admin+ can revoke

**9. Update get_workspace_stats:**
Replace the ownership check `IF NOT EXISTS (SELECT 1 FROM workspaces WHERE id = p_workspace_id AND user_id = auth.uid())` with `IF NOT EXISTS (SELECT 1 FROM workspace_members WHERE workspace_id = p_workspace_id AND user_id = auth.uid())`.

**10. Create get_workspace_usage function:**
As specified in the research doc -- looks up workspace owner's subscription, counts articles by workspace_id. SECURITY DEFINER, returns table with articles_this_period, article_limit, bonus_credits, articles_remaining, plan_id, plan_name, period_start, period_end.
